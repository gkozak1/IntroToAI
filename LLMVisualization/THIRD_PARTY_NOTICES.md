## ONNX Runtime Web

The production browser app loads ONNX Runtime Web 1.23.0 from jsDelivr. ONNX Runtime is an open-source Microsoft project. Refer to its upstream repository for the applicable license and notices:
https://github.com/microsoft/onnxruntime

## Transformers.js / Xenova GPT-2 tokenizer

The production browser app loads `@xenova/transformers` 2.17.2 and the `Xenova/gpt2` tokenizer assets. Refer to the upstream project/model pages for applicable licenses and notices:

- https://github.com/huggingface/transformers.js
- https://huggingface.co/Xenova/gpt2

## GPT-2

The neural-network weights are GPT-2 weights as packaged/exported by Transformer Explainer. GPT-2 was released by OpenAI. The app does not call a paid OpenAI API or other paid inference API.
