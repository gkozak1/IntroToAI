# Usability revision — September 10, 2026

This revision preserves the v6 gradient-descent calculations and all three learning stages while adding:

- A clearly branded Controls workspace with a blue border and Work here badge.
- A plain-language Next action banner that changes for human estimation, weight-only descent, and two-parameter descent.
- A gentle pulse on the next control or button.
- A first-load quick tour, a persistent “Don't show this again” choice, and a How it works button.

The app remains a single, dependency-free HTML file suitable for GitHub Pages and Chromebooks.
